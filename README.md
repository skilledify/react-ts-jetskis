## **🚀 Технологии**
Проект создан с использованием современных инструментов и библиотек:
- ⚛️ **React 19** — основа интерфейса и компонентной архитектуры
- 🔷 **TypeScript** — строгая типизация пропсов, данных каталога и констант
- 💨 **Vite 8** — быстрая сборка и молниеносный HMR в dev-режиме
- 🎨 **Tailwind CSS 4** — утилитарные стили через `@tailwindcss/vite`
- 🧩 **CSS Modules** — инкапсулированные стили компонентов и общие секции
- 🧭 **React Router 7** — клиентская маршрутизация с поддержкой GitHub Pages
- 🎠 **Splide** — плавные слайдеры баннеров и карусели товаров
- 🔍 **ESLint** — проверка кода с `typescript-eslint` и React-плагинами

---

## **🎯 Цель проекта**
Создать современное, стильное и функциональное frontend-приложение интернет-магазина, демонстрирующее:
- адаптивную mobile-first вёрстку с поддержкой различных разрешений экрана;
- сложную клиентскую маршрутизацию и организацию страниц (каталог, карточка товара, корзина, акции, магазины);
- интерактивные элементы (калькулятор доставки, умный поиск, таймер обратного отсчёта, слайдеры);
- чистую архитектуру и масштабируемую структуру кода на React и TypeScript.

---

## **🧠 Основные особенности**
- 🏠 **Главная** — hero-баннер-слайдер, умный поиск с вкладками, карусель категорий, хиты продаж и промо-блок.
- 🗂 **Каталог** — сетка товаров с фильтрацией, сортировкой, «избранным» ❤️ и добавлением в корзину 🛒.
- 📄 **Карточка товара** — детальная галерея, характеристики, вкладки и список магазинов с наличием для самовывоза.
- 🏪 **Магазины** — шоурумы с поиском по адресу, фильтром по городу и отметкой «в наличии».
- 🎉 **Акции** — промокоды с копированием в один клик и живой таймер обратного отсчёта ⏱.
- 🚚 **Доставка и оплата** — интерактивный калькулятор стоимости, таблица тарифов и FAQ-аккордеон.
- 🧭 **Навигация** — хлебные крошки (Breadcrumbs), автопрокрутка наверх (ScrollToTop) при смене маршрута, страница `404`.

## **⚙️ Установка и запуск**

**Требования:** [Node.js](https://nodejs.org/) 20+ и npm.


# Клонирование репозитория
git clone [https://github.com/](https://github.com/)skilledify/react-ts-jetskis.git

# Переход в папку проекта
cd react-ts-jetskis

# Установка зависимостей
npm install

# Запуск локального сервера разработки
npm run dev
