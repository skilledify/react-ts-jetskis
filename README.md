🏍️ Drive Moto

Современный адаптивный фронтенд интернет-магазина моторной техники BRP (гидроциклы, квадроциклы, снегоходы и катера), созданный на React + TypeScript с использованием Tailwind CSS и Splide.

🚀 Демонстрация проекта · 📦 Репозиторий GitHub

🚀 Технологии

Проект разработан с использованием современного стека инструментов:

⚛️ React 19 — компонентная архитектура и управление состоянием

🔷 TypeScript — строгая типизация данных каталога и пропсов

⚡ Vite 8 — быстрая сборка и молниеносный HMR

💨 Tailwind CSS 4 — утилитарная стилизация через @tailwindcss/vite

🎨 CSS Modules — инкапсулированные стили и кастомизация слайдеров

🧭 React Router 7 — клиентская маршрутизация с поддержкой GitHub Pages

🎞 Splide — плавные слайдеры баннеров и карусели товаров

🧹 ESLint — контроль качества кода

🎯 Цель проекта

Создать полноценное, стильное и функциональное коммерческое веб-приложение, демонстрирующее:

адаптивную mobile-first вёрстку с комплексной дизайн-системой;

эффективную работу со сложной фильтрацией, поиском и корзиной товаров;

реализацию интерактивных страниц (каталог, детальная карточка товара, шоурумы, акции, калькулятор доставки);

интеграцию сторонних библиотек и роутинга для production-среды.

🧠 Основные особенности

🏠 Главная страница — hero-баннер-слайдер, умный поиск по вкладкам и хиты продаж

🗂 Каталог товаров — сетка с гибкой фильтрацией, сортировкой, избранным ❤️ и корзиной 🛒

📄 Карточка товара — детальная галерея, характеристики и интерактивные точки самовывоза по магазинам

🏪 Шоурумы — список из 6 магазинов с поиском по адресу и фильтром по наличию

🎉 Акции и скидки — промокоды с копированием в один клик и живой таймер обратного отсчёта ⏱

🚚 Доставка и оплата — интерактивный калькулятор стоимости и подробный FAQ

🧭 Навигация — хлебные крошки (Breadcrumbs), автоматический скролл вверх (ScrollToTop) и страница 404

⚙️ Установка и запуск

Убедитесь, что у вас установлены Node.js (версии 20+) и npm. Выполните следующие команды в терминале:

# 1. Клонирование репозитория
git clone https://github.com/skilledify/react-ts-jetskis.git

# 2. Переход в папку проекта
cd react-ts-jetskis

# 3. Установка зависимостей
npm install

# 4. Запуск локального dev-сервера
npm run dev


Приложение будет доступно локально по адресу: http://localhost:5173/react-ts-jetskis/
